    1. Select the motorcycle model

    Choose the bike under test in New Diagnosis — Honda TMX 125 Alpha, Rusi Macho 125, or Suzuki Smash Carb. Each result is tagged with the selected model.

    2. Position the microphone

    Mount the INMP441 at the standardized position near the exhaust (tambutso) using the gooseneck arm before starting a scan.

    3. Start a diagnosis

    Press Start. The system captures ~3 seconds of audio, extracts MFCC features, and classifies the engine condition using the trained Random Forest model.

    4. Read the result

    The detected condition, confidence percentage, and severity level (0–3) appear under Diagnosis Result. Severity 3 (Knocking) requires immediate attention.

    5. Save or export

    Every classification is automatically logged. Use Save to confirm, View Diagnosis Report for a downloadable PDF, or Export CSV for the full session log.

    Engine condition classes

    Normal, Knocking, Misfire, Valve Ticking — detected acoustically only. MOTOSIRA does not interface with the ignition or electrical system.
